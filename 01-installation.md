# 1.1. Установка Ubuntu Server в VirtualBox

Цель — установить Ubuntu Server в виртуальной машине и после перезагрузки войти в локальную консоль.

## Ход установки

1. Запустила виртуальную машину в VirtualBox с установочного ISO-образа Ubuntu Server. Выбрала английский язык интерфейса и раскладку English (US).
2. Выбрала стандартный вариант Ubuntu Server. На время установки отключила виртуальный сетевой кабель, чтобы не скачивать обновления. Установщик определил сетевой интерфейс `enp0s3`. Продолжила установку без сети.
3. Выбрала автоматическую разметку виртуального диска на 25 ГБ с LVM. Для корневой файловой системы `/` установщик выделил около 11,5 ГБ, для `/boot` — 2 ГБ. Ещё около 11,5 ГБ осталось в группе LVM для дальнейшего использования.
4. Задала серверу имя `srv01` и создала пользователя `user`. На этапе настройки SSH выбрала установку OpenSSH Server.

# 1.2.  Подключение к Ubuntu Server по SSH

Цель — подключиться из Termius на Windows к серверу `srv01` в VirtualBox.

## Настройка сети

Проверила службу SSH командой `systemctl is-active ssh` и получила `active`.
Затем выполнила `ip -br addr`. После установки без сети интерфейс `enp0s3`
был в состоянии `DOWN` и не имел IPv4-адреса.

Подняла интерфейс и запросила IPv4-адрес по DHCP:

    sudo ip link set enp0s3 up
    sudo dhclient -4 enp0s3
    ip -4 -br addr show enp0s3

Интерфейс получил адрес `10.0.2.15/24`. Эту настройку проверила в текущем сеансе.

## Подключение из Windows

В VirtualBox настроила проброс TCP с `127.0.0.1:2222` на `10.0.2.15:22`.
В Termius открыла подключение к `127.0.0.1` на порту `2222`
и вошла на сервер под пользователем `user`.
